# run together in ONE PHPUnit process, in this order, on the default
# WordPress. The gate's shards split the suite across processes, which hides
# a test that only passes because of state an earlier test left behind (and
# one that only fails because of it); a serial run hides the first kind for
# good. Every file here was seen to pass or fail depending on what ran before
# it; its known failures are in tests/phpunit-baseline-canary.txt.
#

# test sets up and tears down everything it relies on.
